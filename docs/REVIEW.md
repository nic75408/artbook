## 验收标准检查清单

### 1. 信息卡字段与层级
- [ ] 作品名（中文 + 英文）使用 `.work-title-zh` 和 `.work-title-en` 类
- [ ] 作者行使用 `.artist-line` 类，包含 `ARTIST` 标签
- [ ] 年代/材质/尺寸行分别使用 `.work-meta-row` 类，包含 `DATE`/`MEDIUM`/`SIZE` 标签
- [ ] 馆藏行使用 `.credit-name` 类，包含 `MUSEUM` 标签
- [ ] 当字段缺失时，对应行不显示且无空白行

### 2. 对齐与版心
- [ ] 画作、信息卡、正文左对齐线一致（误差 ≤ 2px）
- [ ] 画作与信息卡间距：16–24pt
- [ ] 信息卡与正文间距 > 正文段落间距

### 3. 正文结构分段
- [ ] 存在「整体印象」小节（`.essay-section` 第一个）
- [ ] 存在「局部细节」小节（`.essay-section` 第二个，含圆形细节图）
- [ ] 每个小节有 `.essay-section-title` 标题

### 4. 底部工具区与相关推荐
- [ ] 「收藏画作」「下载原图」按钮左对齐与信息卡一致
- [ ] 按钮间距统一 12px
- [ ] 「相关推荐」标题与信息卡左对齐
- [ ] 推荐卡片缩略图尺寸统一 140px 宽
