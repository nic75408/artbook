# Artwork Essay 小标题与段落结构规范

本规范约束作品详情页中「赏析 Essay」区域的小标题出现条件、类型划分与文案匹配方式，确保：
- 小标题是否出现，始终**依据具体内容需要**，而非每段强制挂标签；
- 小标题文案与其下段落内容一一对应，起到清晰提纲作用，而不是装饰性标签；
- 当只有单一类型内容（纯整体印象）时，可以**只保留正文，不渲染任何小标题**，维持干净版面。

规范基于现有 `DESIGN.md` 中的版式与阅读节奏（museum guide 方向），不改变作品数据结构，只为前端工程提供可实现的判断规则。

## 一、小标题出现的条件

段落是否需要小标题，由内容类型与篇幅共同决定。前端不做智能分析，只按后端提供的 `type` 与段落数量执行以下规则：

1. 必须出现小标题的情形
   - 页面包含两种及以上类型的赏析段落（例如 overview + detail，或 overview + technique + closure）。
   - 某一类型下段落内容专注于**不同的分析维度**，需要在视觉上明确区分（如「局部细节：衣物」「局部细节：背景」）。
   - 段落整体长度超过约 2 屏（移动端视口），并且涵盖从整体到局部再到技法的完整分析链路时。

2. 可以不出现小标题的情形
   - 整个 Essay 仅包含**一个段落**，且 `type = overview`，内容为整体印象或总评；此时只渲染正文，不额外添加任何小标题。
   - 多段落但全部为单一叙述逻辑，且 `type` 相同、内部没有明显分析维度变化（例如连续叙述创作背景），由编辑明确标记为不需要小标题；前端仅按 `type` 渲染默认标签或完全不渲染。

3. 禁止出现小标题的情况
   - 后端没有为段落提供 `type` 或类型为未知值时，不允许前端生成「默认」或占位小标题，**仅渲染正文**。
   - 同一篇赏析中，**同一小标题文案不得在不同类型段落上重复出现**（例如「整体印象」不能同时挂在 overview 与 detail 段落前）。

> 工程约束：当段落的 `type` 不在本文定义的列表中，或匹配不到任何小标题文案时，前端仅渲染正文文本，不插入任何标签区域。

## 二、小标题类型与内容的对应关系

为简化实现，赏析段落按 `type` 划分为四大类：

- `overview`  — 整体印象 / 构图与氛围的总评
- `detail`    — 局部细节赏析（面部、身体、衣物、背景等）
- `technique` — 绘画技法/笔触/色彩处理分析
- `closure`   — 收束与点睛（总结、延伸意义、情绪余韵）

每一类 `type` 与推荐小标题文案的对应关系如下表所示。

### 1. overview（整体印象类）

适用内容：作品的整体视觉印象、构图分析、空间与光线氛围等。

- 推荐主标题：
  - 「整体印象」
  - 「作品全貌」
  - 「构图与视线」
- 典型段落示例：
  - 描述画面开阔的视野、构图的稳定与平衡感。
  - 分析主体物在画面中的位置、视线引导路径。

约束：
- 当整篇仅有 overview 一段时，可以不渲染「整体印象」小标题，仅保留正文。

### 2. detail（局部细节类）

适用内容：某个具体局部的精彩处理，如面部表情、身体姿态、衣物纹理、背景环境等。

- 推荐主标题：
  - 「局部细节：面部」
  - 「局部细节：身体」
  - 「局部细节：衣物」
  - 「局部细节：背景」
- 典型段落示例：
  - 分析面部表情中眉眼、嘴角的刻画如何传达情绪。
  - 描述身体姿态的动态张力与结构准确性。
  - 讨论衣物褶皱、材质、纹理的细腻表现。
  - 讲述背景山石、建筑或植被的处理对空间感的贡献。

约束：
- 同一作品中，同一局部类小标题（如「局部细节：衣物」）只能挂在对应局部分析段落之前，不能用于整体背景或其他内容。

### 3. technique（技法解读类）

适用内容：绘画技法、笔触语言、用色方案、材质处理方法等的分析与解释。

- 推荐主标题：
  - 「技法解读」
  - 「笔触与肌理」
  - 「色彩与光线」
- 典型段落示例：
  - 解释画家如何通过薄涂、厚涂或罩染叠加出层次与深度。
  - 描述线条的书法性运用如何增强画面的节奏感。
  - 分析色彩冷暖关系、明暗对比对情绪与空间的影响。

约束：
- 技法类小标题应挂在明确分析方法、材料和操作的段落前，不应用于纯叙事或背景介绍。

### 4. closure（收尾点睛类）

适用内容：赏析的总结、作品意义的提升、情绪余韵的点明等。

- 推荐主标题：
  - 「收尾点睛」
  - 「余韵与意义」
- 典型段落示例：
  - 总结作品在美术史中的位置或对后世的影响。
  - 描述观者在作品前停留的情绪体验和思考方向。

约束：
- closure 段落应位于赏析的末尾，仅出现一次；禁止在同一篇文章中重复使用「收尾点睛」挂在不同段落上。

## 三、单段赏析场景的处理策略

当一件作品的赏析仅由一个段落构成时，为保持简洁版面，可按以下策略处理：

1. `type = overview`
   - 默认不渲染任何小标题，仅显示正文。
   - 若编辑明确要求（例如专题文章），可选择渲染「整体印象」作为唯一小标题。

2. `type = detail`
   - 若该作品仅需强调单一局部（如「局部细节：面部」），推荐保留对应小标题，以便用户一眼识别分析焦点。

3. `type = technique` 或 `type = closure`
   - 视具体内容决定是否需要小标题。若内容本身已在首句中点明分析方向，可选择只渲染正文。

> 设计意图：
> - 单段 overview 保持极简，正文直接从版式上承接标题与作品图。
> - 单段 detail / technique / closure 通过少量小标题帮助用户理解这段「在讲什么」，避免误认为是继续的整体叙述。

## 四、段落类型 → 小标题文案 → 渲染策略表

工程实现应按如下表格硬编码或配置，而不是做自然语言分析。

| 段落 type   | 推荐小标题文案                     | 是否必须渲染小标题                    |
|-------------|------------------------------------|---------------------------------------|
| overview    | 整体印象 / 作品全貌 / 构图与视线   | 当仅一段且为 overview 时可不渲染      |
| detail      | 局部细节：面部/身体/衣物/背景     | 当存在多类型段落或多局部分析时必须渲染 |
| technique   | 技法解读 / 笔触与肌理 / 色彩与光线 | 当作为独立分析段落时推荐渲染          |
| closure     | 收尾点睛 / 余韵与意义             | 仅末尾出现一次，推荐渲染              |

补充约束：
- 对于 `detail` 类，具体小标题需根据作品的主分析对象选择（例如衣物、背景），不得使用「局部细节」空泛表述。
- 同一文案在同一篇赏析中最多出现一次，小标题文案与段落内容必须保持语义一致。

## 五、实现约束与前端行为说明

此处给出供前端工程实现的明确行为约定：

1. 不做智能推断：
   - 前端只根据后端提供的 `type` 与位置信息，按上文表格与规则决定是否渲染小标题及文案内容。
   - 当 `type` 不在 `overview / detail / technique / closure` 四类中时，前端只渲染正文，不生成任何默认标签。

2. 渲染顺序与结构：
   - 小标题区域紧贴其对应正文段落之前，采用 `typography.section-title` 或专用标签样式，保持比正文略大的层级。
   - 当有多段落时，小标题与正文之间保持统一的垂直间距，与 `DESIGN.md` 中 `section-v` 一致或为其简单倍数。

3. 复用与扩展：
   - 后续如需新增 `type`（例如 `context` 用于历史背景），应在本规范中补充对应小标题文案与渲染策略，再由工程实现。
   - 未在规范中定义的类型，在实现前不予渲染任何小标题，避免出现语义漂移和视觉噪音。

该规范作为作品 Essay 小标题与提纲结构的唯一来源，与 `DESIGN.md` 一并维护。当产品或编辑希望调整段落类型或标签策略时，应先更新本文，再由工程按更新后的规则实现。
