如何安装 PWA 到主屏幕

  1. iOS Safari: 点击分享按钮 → "添加到主屏幕"
  2. Android Chrome: 点击右上角菜单 → "安装应用" 或 "添加到主屏幕"
  3. Desktop Chrome: 点击地址栏右侧的安装图标

安装后，主屏幕上的应用图标将显示为上方的"艺"字图标。
