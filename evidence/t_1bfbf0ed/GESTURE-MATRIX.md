### 2.3 手势判定优先级（沿用 SPEC §2）

`pointerdown` → 校验起点 → 判定 `disqualified`（相关推荐区 / 图片查看器打开 /
转场进行中 → 放弃）→ 判定 `axis`：
- **优先**：起点在左边缘 30px 内 → `axis = 'edge-back'`（新规范；当前代码检测的
  是右边缘，需修正）
- 起点在页顶 + 向下滑 dy>0 → `axis = 'v'`
- 主导轴 = 水平 + 有 folioCtx → `axis = 'h'`
- 都不满足 → `disqualified = true`

判定后不换轨（避免中途方向抖动）。

## 6. 全站规则总结（八条硬约束）

1. **左箭头 `←` 只在 push 页出现**：详情页 / 收藏夹 / 聚合页各一枚，位置和外观
   完全一致（40×40 雾玻璃胶囊，左上角 fixed）。
2. **`✕` Close 图标全站不再出现**：t_a312968d 已废弃详情页的 X；如果未来引入
   modal sheet 页，才可以启用 `✕`。
3. **左边缘向右滑动 = 返回**（跨全站二级页面统一）；起点判据 x ≤ 30px，触发
   判据 dx ≥ 80px 且 |dx| > |dy|。修正后与 iOS 系统级手势方向一致。
4. **右边缘、右滑不承担返回语义**——避免用户在其他 App 里做的动作在 artbook 里
   意外触发返回。
5. **顶部下滑 = 返回**（仅详情页）：scrollY=0 起手 + dy > 0，触发判据位移 ≥ 96px
   或速度 ≥ 0.45px/ms；命名统一为「返回」，不叫「退出」。
6. **列表页顶部下滑不接管**：避免与 pull-to-refresh 心智冲突。
7. **detail 页的横向手势 axis 一旦判定，不允许换轨**——防止 diagonal 输入导致方向
   抖动（SPEC §2 已有的规则，保留）。
8. **Modal 组件的关闭手势不与 push 页共用一套 API**：viewer 用单击，sheet 用
   点击背景/Cancel。规范上禁止把 `attachEdgeSwipeBack()` 挂到任何 modal 元素上。
