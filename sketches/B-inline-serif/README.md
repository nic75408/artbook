## Variant: B · 内联文字链（展签风）

### 设计立场
美术馆展签的做法：图 → 品名 → 一行小字"→ 了解更多"或"Continue reading"。
按钮容器是**app 时代的语言**，不是画册/展签的语言。把容器全部拿掉，
只留衬线金字 + 一根细横线。整屏变成一张展签的排字。

### 关键选择
- **形态**：无背景、无边框、无 padding；三行文字堆叠：
  - `Continue reading` — Georgia 斜体 15px，金色，字距 0.08em
  - 48px 金色 1px 细横线，opacity 0.6
  - `了 解 更 多` — Songti SC 13px，字距 0.3em（疏排），二级灰
- **位置**：画作+题名下方 28px 居中
- **色**：金 + 二级灰，一点儿黑都不加
- **交互**：`:active` 时横线伸长到 64px、`了解更多` 转为主墨色，
  书页翻页的暗示
- **不做**：不用胶囊、不用圆、不放 chevron 箭头（陨落感 → 用横线代替）

### 权衡
- 强在：**气质最像美术馆导览**；这是三案里唯一让"了解更多"看上去像内容而不
  像控件的方案；与页面已有的衬线大标题（Art Daily / 雷神图屏风）血统同源
- 强在：视觉重量最轻，画作是唯一焦点
- 弱在：**可点击性弱**——没有明显容器，第一次用可能会犹豫；但赤拔已经在
  用主图/整个卡片作为主动作，这里的"了解更多"本来就是二级路径的辅助入口
- 弱在：与日期胶囊、收藏夹按钮的语言**不同族**了——那两处是胶囊控件，这里
  是文字。系统一致性上让位给了气质

### 最适合
- 视觉优先、体系一致性优先级次之的场景
- 赤拔倾向"这个 app 应当像一本画册而不像一个 app"的语境
- 已有页面/生成器/收藏夹页里的"次要入口"也都可以复用同一形式
