## Variant: C · 极细描边圆按钮

### 设计立场
旧版圆盘的问题不是"圆"本身 —— 是黑填色、环绕字、旋转动效三件套让它太重。
把圆的几何留下，把重量卸掉：44px 米底 + 1px 金色环 + 6px 外再一圈细线，
一枚"印章"式的入口。既不失个性，又不与美术馆调性打架。

### 关键选择
- **形态**：44px × 44px 圆，`bg #F5F1EA` 底 + 1px `--gold` 描边 + 6px 空隙外
  再一圈 1px `--line` 细环 = 双环视觉，像图章
- **图标**：单个 16px chevron `›`，1.5 stroke，round linecap
- **位置**：画作+题名下方 24px 居中（不再是右下角固定！）
- **色**：金 + 米 + 少量灰线，没有一点黑填色
- **交互**：`:active` 时圆填金、chevron 反白、`scale(0.96)`
- **不做**：不旋转、无环绕字、无阴影

### 权衡
- 强在：**过渡最平滑**——从旧版的黑圆盘变成这个，赤拔的肌肉记忆不需要重训
  练；圆的"点击目标"心智模型保留
- 强在：视觉上有独特符号感（双环像画册页码或印章），比 A 有个性
- 弱在：44px 触摸目标处于"够用但不宽裕"的边界；不如 A 的胶囊更放心
- 弱在：与页面其他控件（胶囊）**不同族**，是页面上唯一的圆——但因为它足
  够克制，"唯一"变成了"点睛"，是可接受的不一致
- 弱在：图标语言是纯 chevron `›`，比 A 的"文字 + chevron"信息量少，第一次
  可能需要靠上下文才知道是"了解更多"

### 最适合
- 想保留"圆按钮"这个符号但把重量彻底降下来的场景
- 赤拔希望"页面里有一个不一样的点缀"而非全部胶囊化的场景
