## Variant: A · 双胶囊底栏

### 设计立场
「了解更多」不是主动作 —— 主动作是点击画框进详情。所以它应当降级为一个
和收藏夹按钮、日期胶囊完全同族的米色胶囊，视觉上与整套控件"是一家人"。

### 关键选择
- **形态**：米色胶囊 = `bg + 1px line + pill radius`，与 `.fav-btn` / `.date-capsule` 同族
- **位置**：画作+文字模块下方居中，紧贴 `.names` 20px
- **文字**：`了解更多` + 金色 chevron `›`，衬线灰字，1.6 stroke chevron
- **尺寸**：padding 8×18，视觉重量 ≈ 收藏夹按钮
- **色**：底 `--bg (#F5F1EA)`，边 `--line`，文字 `--ink-2`，chevron `--gold`
- **交互**：`:active` 时描边转金色、底切浅纸色，暗示进入
- **不做**：不旋转、不用环绕字、不填黑

### 权衡
- 强在：**体系统一**，页面上所有交互控件都是"米色 + 细线 + 金字点缀"，
  一套语言解释三个按钮（收藏夹 / 了解更多 / 日期）
- 强在：**触摸目标够大**，一次可点，位置符合拇指自然停留区
- 弱在：视觉最不"个性"，看上去像文档站的通用组件；牺牲了旧版圆盘的
  "标志性"意味
- 弱在：与日期胶囊都在下部，二者纵向距离要拉开否则视觉会挤

### 最适合
- 优先考虑**系统一致性和可用性**的场景
- 赤拔认为"控件应当克制、别和内容抢戏"的语境
