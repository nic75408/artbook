## 定稿 B 的核心理由

1. **血统直系**：赤拔 2026-08-26 拍板方向 B（美术馆导览），本方案是三案里
   最像美术馆展签的一个。品味档案条目"visual tone: warm paper, serif
   Chinese, generous breathing space, slow motion"逐条对得上。
2. **彻底解毒**：赤拔截图批评"黑色实心圆 + 环绕字与美术馆调性不融合"，B
   的解法是把整个按钮容器都拿掉，视觉重量从"控件"降为"内容"，比降级
   最彻底。
3. **层级分明**：DESIGN.md 决策日志新增"交互层级两层制"——主动作 = 胶囊
   控件，二级内容路径 = 文字链。让 B 与其他控件不同族成为规范而非漏洞。
4. **可用性补偿**：`.learn-inline` 加 `padding: 8px 20px` 扩大点击热区，
   `:active` 时横线伸长 + 中文转墨色作按压反馈，`prefers-reduced-motion`
   已豁免。

## 落选方案的价值

- **A 双胶囊**：不消失，进入 DESIGN.md 作为**主动作胶囊范式**的规范来源。
  详情页的收藏 / 生成 / 分享等一级动作沿用 A 的胶囊做法（部分已在
  `.action-btn` 里）。

  详情页 `.detail-close` 圆按钮，C 的「1px 描边 + 双细线」处理是一条
  更克制的圆按钮备选路径，供未来场景使用。
